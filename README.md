# Milestone 1 - Digital components

Mỗi khối được đặt trong một thư mục riêng. Mã SystemVerilog nằm trong `rtl/`,
testbench nằm trong `tb/`; tài liệu của từng khối ở `README.md` trong thư mục đó.

| Khối | Thư mục | Trạng thái |
|---|---|---|
| Adder | `adder/` | Khung thư mục |
| Magnitude comparator | `magnitude_comparator/` | Khung thư mục |
| Shifter | `shifter/` | Khung thư mục |
| ALU | `alu/` | Khung thư mục |
| Register file | `register_file/` | Đã có RTL và testbench |
| Synchronous memory | `synchronous_memory/` | Khung thư mục |
| Asynchronous memory | `asynchronous_memory/` | Khung thư mục |

Các khối đang ở trạng thái khung chưa có RTL/testbench vì chưa có đặc tả giao
diện và hành vi. Thêm source vào `rtl/` và testbench vào `tb/` của khối tương ứng.
